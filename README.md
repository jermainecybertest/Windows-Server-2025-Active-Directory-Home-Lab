# 🖥️ Windows Server Home Lab – IT Support Skills Project

This project is a hands-on home lab where I built a small business-style Windows network to practice real-world IT Support and Help Desk tasks.

The lab simulates how companies manage users, computers, security settings, and shared folders inside a corporate network.

---

## 🎯 Project Goals

- Learn how businesses manage employee logins and computers
- Practice troubleshooting common Help Desk issues
- Understand how security rules are applied across company devices
- Gain hands-on experience with Windows Server tools used in IT jobs

---

## 🛠️ Technologies Used

- Windows Server  
- Windows 10 Client  
- VMware Workstation  
- Active Directory  
- Group Policy  
- NTFS & Share Permissions  

---

## 🧩 Lab Setup Overview

| System | Role |
|-------|------|
| Windows Server | Domain Controller (manages users, security, and policies) |
| Windows 10 VM | Employee workstation joined to the company network |
