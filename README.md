# 🖥️ Active Directory Home Lab Project

This project simulates a small business network using **Windows Server** and **Active Directory**. The goal is to demonstrate hands-on experience with common IT support tasks, including user management, account security, and file access control.

---

## 🏢 Domain Setup (Corporate Network Environment)

**Configured a Windows Server** to serve as the central management platform for users, computers, and security policies across the company network.

### Key Actions
- Installed **Active Directory Domain Services (AD DS)**
- Promoted the server to a **Domain Controller**
- Deployed an internal company domain
- Configured **DNS** to enable devices to locate network resources efficiently

### Impact
This setup mirrors how businesses centrally manage employee logins and computers. It provides a foundation for daily helpdesk operations, such as account troubleshooting and network management.

## 👥 User & Department Management

**Structured a realistic corporate environment** by creating departments and assigning users according to organizational roles.

### Key Actions
- Created **Organizational Units (OUs)** for departments:
  - Accounting
  - Management
  - Sales
- Added users to the appropriate departments
- Implemented **security groups** to streamline access control and permissions

### Impact
This demonstrates routine helpdesk responsibilities, such as onboarding new employees, resetting passwords, and managing group memberships.

## 🔐 Company Security Policies

**Enforced enterprise-level account security policies** to safeguard user accounts from unauthorized access.

### Key Actions

### Impact

## 📂 File Sharing & Access Control

**Deployed a departmental file server** and controlled access to ensure employees could only access resources relevant to their roles.

### Key Actions
- Created **shared folders** for each department
- Assigned permissions via **security groups**
- Differentiated between:
  - **Share permissions** (network-level access)
  - **NTFS permissions** (file-level access)
- Utilized **Effective Permissions** to troubleshoot access issues

### Impact
Simulates common helpdesk requests, such as resolving “I can’t access this folder” tickets, demonstrating practical problem-solving skills in file access management.
